## 🧪 Demo Application

The `sdk-playground` directory contains a complete demo environment:

- **demo-app**: A Spring Boot application with various controllers demonstrating SDK capabilities.
- **demo-client**: A consumer application that uses the generated SDK to communicate with `demo-app`.

See the [Developer Guide](Developer-Guide.md#sdk-playground) for more details on running the demo.
